6. RAM (8 GB): MEDIR n8n ANTES Y DESPUÉS
================================================================
El modelo corre en la nube (D16): lo que crece es n8n (nodos, memoria de
chat, ejecuciones guardadas). Procedimiento, en PowerShell, mismas
condiciones las dos veces (VS Code, uvicorn del 8000 y Docker abiertos;
navegador solo con el chat):
  1. Reposo: 3 tomas con 1 min entre ellas de
       docker stats --no-stream --format "{{.Name}};{{.MemUsage}};{{.CPUPerc}}"
     y de la memoria libre de Windows
       (Get-CimInstance Win32_OperatingSystem).FreePhysicalMemory
     más el proceso de WSL (Get-Process VmmemWSL, WorkingSet64), porque
     docker stats no cuenta lo que reserva WSL.
  2. Carga: un bucle que anota esas tres cifras cada 5 s en un CSV del
     scratchpad mientras Gabi hace 3 conversaciones completas del guion.
  3. Después: 5 min de reposo y otras 3 tomas (¿n8n devuelve la memoria?).
  "Antes" = solo Agente 1 (hoy); "después" = Agente 1 + Agente 2 + memoria.
  Criterio propuesto (P12): si la memoria libre de Windows baja de 1 GB en
  la carga, se anota como limitación y se revisa la ventana de Simple
  Memory y la retención de ejecuciones de n8n antes de seguir.
